Agora vamos implementar a modelagem base do jogo.

## Contexto

O projeto é **Reinos & Promessas**, um jogo de estratégia territorial no Antigo Testamento.

Estamos criando primeiro um MVP local, sem backend e sem multiplayer.

## Objetivo desta etapa

Criar os tipos TypeScript principais e os dados estáticos iniciais do jogo.

## Tipos necessários

Crie tipos para:

- GameState
- Player
- Territory
- Region
- ResourceState
- Card
- Objective
- StartingPack
- GameMode
- TurnState
- ActionType
- TerritoryState
- BotDifficulty

## Recursos do jogador

Cada jogador deve ter:

- provisão
- ouro
- influência
- legado
- cartas na mão
- objetivo secreto
- personagem ativo, se houver

## Recursos/estado de território

Cada território deve ter:

- id
- nome
- região
- tipo
- produção
- defesa natural
- fé base
- fé atual
- tropas neutras iniciais
- tropas atuais
- dono atual
- conexões
- melhorias
- estado atual: neutro, controlado, ocupado/instável, pressionado, rebelde
- ponto forte
- ponto fraco
- descrição/contexto

## Tipos de território

Use:

- comum
- estrategico
- sagrado
- capital

## Estados de fé

A fé vai de 0 a 100:

- 0–19: rebelde
- 20–39: fraco
- 40–59: estável
- 60–79: forte
- 80–100: fiel/protegido

## Modos de partida

- rápido: 100 legado
- padrão: 150 legado
